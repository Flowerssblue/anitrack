# AniTrack

Aplicación Android para llevar el seguimiento de tu anime: tu lista, tu progreso episodio por episodio, calendario de emisión, recomendaciones y comentarios.

Este repositorio solo contiene las descargas (APK) de la aplicación.

## Descargar

Ve a la sección [Releases](../../releases/latest) y descarga el archivo `AniTrack-x.y.z.apk`.

## Instalar

1. Descarga el APK en tu teléfono Android.
2. Ábrelo. Si Android lo pide, permite instalar aplicaciones desde esta fuente (el navegador o el administrador de archivos que usaste).
3. Pulsa **Instalar**.

Requiere Android 6.0 o superior.

## Actualizaciones

Las mejoras pequeñas llegan solas dentro de la app: verás el aviso «Actualización lista». Cuando salga una versión que cambie la parte nativa, tendrás que descargar el nuevo APK desde Releases e instalarlo encima de la anterior.
